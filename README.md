# pmergny.github.io

Personal academic website for Pierre Mergny, hosted with GitHub Pages and Jekyll.

## Editing the website

- Home page: `index.md`
- Publications: `_pages/publications.md`
- Teaching: `_pages/teaching.md`
- CV page: `_pages/cv.md`
- Sidebar / identity: `_config.yml`
- Navigation: `_data/navigation.yml`
- Styling: `assets/css/style.css`
- Profile picture: `assets/images/bio-photo.jpg`
- PDF CV: `assets/CV.pdf`

The repository intentionally uses only a very small amount of Jekyll functionality, so it remains easy to maintain and deploy with GitHub Pages.
